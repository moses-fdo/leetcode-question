### How to use this roadmap

1. Work through each pattern **top to bottom** — phases increase in difficulty and build on prior concepts.
2. Tick the checkbox (change `☐` to `☑`, or just track separately) once a problem is solved *without* hints.
3. Give ⭐-heavy problems a second and third pass a few days apart.
4. Capstone phases mix problems from earlier phases — treat them as your readiness check before moving to the next pattern.

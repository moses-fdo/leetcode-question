🧠 Pattern Cheat Sheet & Invariants

Quick lookup guide for recognizing problem cues, invariant strategies, and target time/space complexities.

Pattern / Variant Recognize When (Problem Cues) Core Invariant & Strategy Target Complexity
Two Pointers (Opposite) Sorted array, pair/triplet target sums, palindromes Squeeze pointers inward based on nums[l] + nums[r] comparison O(N) time · O(1) space
Fast & Slow Pointers Cycles in lists/arrays, middle node, duplicate finding Floyd's cycle detection; two speeds guaranteed to intersect if cycle exists O(N) time · O(1) space
Fixed Sliding Window Subarray or substring of fixed size K Add nums[r], drop nums[l], slide window of size K continuously O(N) time · O(1) space
Variable Sliding Window Longest or shortest valid subarray/substring Expand r; while invalid, shrink l until window property is restored O(N) time · O(1) space
At Most K Trick "Count subarrays with exactly K distinct elements or sum" Transform to: count(exact K) = atMost(K) - atMost(K - 1) O(N) time · O(K) space
Monotonic Deque Window min/max queries, max sum with distance constraint Maintain elements in monotonic order; discard candidates that cannot win O(N) time · O(K) space
Prefix Sum + Hashmap Count or find subarrays with sum equal to K sum(i..j) = P[j] - P[i-1]; check if P[j] - K exists in prefix frequency map O(N) time · O(N) space
Prefix Sum + Modulo Subarray sum divisibility by K Identical remainders P[j] % K == P[i-1] % K bound a divisible range O(N) time · O(K) space
2D Prefix Sum Submatrix / rectangle range sum queries Inclusion-exclusion principle on bounding corners in O(1) per query O(MN) prep · O(1) query
Difference Array Multiple range updates [l, r] += v, single final read Range update: diff[l] += v, diff[r+1] -= v; reconstruct via prefix sum O(1) update · O(N) read
Merge Intervals Overlapping intervals, interval union, insertion Sort by start time; if start <= last_end, merge; else push new interval O(N log N) time · O(N) space
Greedy Intervals Maximum non-overlapping intervals, minimum arrows/cuts Sort by end time; greedily pick interval finishing earliest to maximize room O(N log N) time · O(1) space
Sweep Line Peak concurrent active events, room booking count Decompose intervals into (start, +1) and (end, -1) points; sort and scan O(N log N) time · O(N) space
Interval + Heap Room assignment by index, meeting schedules Min-heap tracks currently active allocations by finish time; free on expire O(N log N) time · O(N) space
1D Decision DP (Take / Skip) Adjacent dependency, maximize sum without adjacent, robber problems dp[i] = max(dp[i-1], nums[i] + dp[i-2]); optimize to 2 variables O(N) time · O(1) space
Kadane / Subarray DP Max/min subarray sum/product contiguous segment dp[i] = max(nums[i], dp[i-1] + nums[i]); product tracks min and max O(N) time · O(1) space
0/1 Knapsack (Subset Sum) Target sum, partition equal subsets, item used at most once Reverse inner loop: dp[w] = dp[w] || dp[w - num] from target down to num O(N·W) time · O(W) space
Unbounded Knapsack (Coins) Min coins or coin combinations, items reusable infinitely Forward loop: outer coins = combinations; outer amount = permutations O(N·A) time · O(A) space
2D Grid DP Unique paths, minimum path sum, obstacle avoidance dp[r][c] = grid[r][c] + min(dp[r-1][c], dp[r][c-1]); compress to 1 row O(R·C) time · O(C) space
LIS (Increasing Subsequence) Longest increasing subsequence, non-overlapping envelopes Patience sorting with binary search on tails array O(N log N) time · O(N) space
2D String Alignment (LCS / Edit) Longest common subsequence, edit distance, string transforms Match: dp[i-1][j-1]; Mismatch: min/max(dp[i-1][j], dp[i][j-1]) O(M·N) time · O(N) space
State Machine DP (Stocks) Buying/selling stocks with cooldown, fees, or k transactions Explicit state variables (hold, sold, rest) with transitions O(N) time · O(1) space
Interval DP Burst balloons, merge stones, matrix chain multiplication Loop chain length $L$, then left $i$, then split point $k \in [i+1, j-1]$ O(N³) time · O(N²) space
Tree DP Binary tree camera placement, max path sum, tree robbery Post-order DFS returning state tuple (e.g. (rob, not_rob)) to parent O(N) time · O(H) space
Bitmask & Graph DP Visit all nodes (TSP), partition to K subsets, matrix DAG path State representation with bitmask integers dp[mask][u] or DFS + memo O(N²·2ᴺ) time · O(N·2ᴺ) space
Disjoint Set (Union-Find) Connected components, dynamic connectivity, cycle detection in undirected graph Find with path compression, Union by rank: find(x) == find(y) indicates cycle O(α(N)) amortized · O(N) space
Grid as Graph Matrix traversal, island counts, perimeter, multi-source rotting / spreading Multi-source BFS queue initialization or 4-directional DFS boundary sinking O(R·C) time · O(R·C) space
Bipartite Graph (2-Coloring) Verify if vertices can be partitioned into 2 independent sets BFS/DFS alternating color assignment (0 and 1); conflict indicates odd cycle O(V + E) time · O(V) space
Kahn's Algorithm (Topological) Task scheduling with dependencies, compile ordering, cycle detection in DAG Compute in-degrees; enqueue 0 in-degree nodes; pop and decrement neighbor in-degrees O(V + E) time · O(V + E) space
Dijkstra's Algorithm Single-source shortest path on weighted graph with non-negative edge weights Min-heap priority queue storing (dist, node); relax edge if d + w < dist[v] O(E log V) time · O(V) space
Floyd-Warshall Algorithm All-pairs shortest paths or transitive reachability on dense graphs 3 nested loops (intermediate $k$ outermost): dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]) O(V³) time · O(V²) space
Kruskal & Prim MST Minimum cost to connect all vertices into a single spanning tree Kruskal: sort edges and add via Union-Find; Prim: greedy min-heap cut relaxation O(E log E) time · O(V + E) space
Binary Lifting (Tree Ancestor) $K$-th ancestor of tree node, Lowest Common Ancestor (LCA) queries in $O(\log N)$ DP table up[u][k] = up[up[u][k-1]][k-1] storing powers-of-two ancestors O(N log N) prep · O(log N) query
